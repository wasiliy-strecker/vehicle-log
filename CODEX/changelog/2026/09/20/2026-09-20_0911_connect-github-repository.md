https://github.com/wasiliy-strecker/vehicle-log als origin eingerichtet.

committeten App-Stands einschließlich dieses Eintrags mit git push -u origin main.
Kein Force-Push und keine Änderung an App-Code, Paketnamen oder Versionsnummern.

Vorbereitung geprüft: GitHub-Repository leer, lokaler Arbeitsstand sauber,
SSH-Zugriff verfügbar. Dokumentation und git diff --check geprüft.
Die vorhandenen Code-Prüfungen aus Commit 1f07e39 gelten unverändert.
Für diese Git-Anbindung sind keine neuen Flutter-Prüfungen, Builds oder
Smartphone-Tests notwendig. Nach dem Push lokale und entfernte Commit-ID
sowie Upstream-Zuordnung prüfen.
