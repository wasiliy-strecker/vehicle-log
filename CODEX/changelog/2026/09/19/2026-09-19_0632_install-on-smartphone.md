# Fahrzeugakte auf dem Smartphone installieren

Vorhandene Dev-APK 1.0.0+1 auf dem verbundenen Smartphone BVL-N49 installiert.
Zielpaket `com.appfactory.vehicle_log.dev` war zuvor nicht installiert.
APK-Identität und Debug-Variante geprüft. Installation mit
`adb install -r -t -g --no-streaming` erfolgreich.

Anschließend die MainActivity gestartet. Android bestätigt den Start mit
`Status: ok`. Installierte Version 1.0.0, Versionscode 1 und Debug-Flag geprüft.
Kein neuer Build, keine Datenlöschung und keine Änderungen am Anwendungscode.
